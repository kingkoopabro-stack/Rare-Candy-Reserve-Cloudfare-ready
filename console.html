Developer Console.

Update inventory fast — prices, SKUs, stock, photos — then export and push to the repo. Edits save to this browser only until you export them.

How this works (v1): every change below is stored in this browser's localStorage and shows up in the console + preview right away. It does not change the live site or rewrite site.js on disk. To go live: hit Export catalog JSON (or Export site.js snippet), then push that file to the repo. Photos are downscaled to 800px JPEG before saving — browser storage is limited (~5MB), so keep uploads small. VCR Special flags feed the VCR Coin staking rewards on the home page.

.rcr project files

Save it. Load it anywhere.

Projects save as .rcr files — Rare Candy Reserve project files. Just like FL Studio's .flp files, but ours. Save one to your PC or phone, load it back any time, and keep building on it. In the DAW, hit 💾 Save Project and it downloads a .rcr file; 📂 Load Project opens one back up — projects saved earlier as .json still open too.

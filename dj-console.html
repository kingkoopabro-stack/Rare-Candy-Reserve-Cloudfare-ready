      One-time setup, in order

      1. Install VB-Cable first — run its setup as administrator, restart if it asks. Until it’s installed, CABLE Input won’t appear in any list, and pointing a player at a missing device can crash it.
      2. In VLC: Tools → Preferences → Audio → Device → CABLE Input (VB-Audio Virtual Cable) → Save.
      3. In BUTT: set the audio device to CABLE Output — that’s the end of the cable BUTT records from.
      4. For Icecast: server 127.0.0.1, port 8000, user source, mountpoint /vitanova, MP3 128k. Start Icecast as admin and leave its console open while streaming.
      5. Result: notifications, browser audio, and game sounds stay on the TV speakers. Only what you route into the cable reaches listeners.
